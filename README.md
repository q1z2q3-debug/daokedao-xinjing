# 润泽说 道可道之心经通释

《般若波罗蜜多心经》二百六十字的**完整通释**：一本可读、可查、可在手机上离线打开的书。

全书 **71,207 字**，三十六节：总序、卷首语、卷首附说、图一至图三、分释篇一至十一、附录总说、附录 A–O（M、N 留空）、附录一至六、跋、编辑札记（22 条）。

> 这本书的全部工作，在于**把每一个字还原到它的字源与本义，再让经文自己把般若讲出来**。它不取玄虚之说，也不做宗教附会；以「佛说 A — 即非 A — 是名 A」为标尺，落到「人如何不被自己的念头困住」。

---

## 一、体例：一篇五层，末附小结

| 层 | 做什么 |
|---|---|
| 原文 | 玄奘译本为底本，异译与梵本对读处随文出注 |
| 原文正读 | 断句、句读、字面直解，先把话读通 |
| 般若深解 | 以「说—非—名」三段拆解，破能所、破法执 |
| 老庄对照 | 《老》《庄》同参处标明同异，不强行混同 |
| 易传锚定 | 以《易传》「寂然不动，感而遂通」等句作旁证 |
| 本节小结 | 一段收束，接「下一篇」 |

底层模型为「三才五蕴太极空杯」与「佛说 A（阴）— 即非 A（阳）— 是名 A（太极）」。
