# 五蕴三维器：几何与渲染契约

两只器，一句话：**杯以容，管以通**。杯是「色为底、受想行识四瓣竖壁」；管是「五蕴五瓣纵壁、横放无底」。

## 一、几何契约

| 项 | 杯（cup） | 管（pipe） |
|---|---|---|
| 五蕴配位 | 色＝杯底；受／想／行／识＝四瓣 | 色受想行识＝五瓣，色亦一瓣 |
| 瓣数与角度 | 4 瓣，各 90° | 5 瓣，各 72° |
| 分瓣方向 | 沿圆周切，**竖切通体**（沿杯高） | 沿圆周切，**沿管长通体** |
| 朝向 | 直立，杯口朝上 | 横放，管轴沿 X |
| 单独的底 | 有（色） | 无 |
| 空 | 杯内腔＝容 | 管腔＝通 |

禁：同心五层、横向条带、把管沿长度切成五段、把杯画成四块侧板、给管单独画底。

## 二、建模实现

- 壁瓣用 `THREE.Shape` 画外弧→内弧回绕的环形扇区，`ExtrudeGeometry` 挤出，`seg=72`。
- 瓣间留细缝：外弧起止各缩 `GAP≈0.006` 弧度，让五色之间有一条暗线，读得出「瓣」。
- 管的挤出轴默认 Z，`geo.rotateY(Math.PI/2)` 转到 X 轴，再 `translate(0,0,-L/2)` 让管体居中。
- 实心态不能把内半径归零：夹到 `0.0016` 防退化面；同时「空」的图例状态改成「空尽，不通」。
- 管腔要读出纵深：加一层 `BackSide`、`depthWrite:false` 的薄壳，贴沿管长由暗到透明的 CanvasTexture（alpha 0.62→0.34→0），半径 `Ri-0.006`、长度 `L-0.03`，`rotation.z=-π/2`、`scale.set(Ri-0.006,1,Ri-0.006)`。这层只做「看不见的里面」，不参与实体几何。

## 三、颜色：必须做 sRGB 线性化

十六进制颜色**先** `new THREE.Color(hex).convertSRGBToLinear()`，再交给材质；同时 `renderer.outputEncoding = sRGBEncoding`、`toneMapping = NoToneMapping`。漏掉线性化或改用 ACESFilmic 加猛光，五色会被洗成灰粉灰蓝——这是最常见、也最像「配色难看」的翻车。

杯（赭调）：
`色 #b78a55`、`受 #cf8d86`、`想 #dfc06b`、`行 #93b79b`、`识 #8ea8cc`

管（参考图那套）：
`色 #2f4a6d`、`受 #5fa382`、`想 #c2542a`、`行 #b98a95`、`识 #7fa3c4`

两只器各自成套，不要混用；五蕴次序固定，只是视角在换。

## 四、光照与阴影

- 三光源：主平行光定形与投影方向，补光把暗部拉回可读，环境光（`RoomEnvironment` 过 PMREM 或低成本半球光）给可信度。只给一盏平行光＝死平。
- 接触阴影必须有：平面阴影用 `ShadowMaterial`。**`THREE.LegacyShadowMaterial` 在 r128 不存在，构造即抛错并中断整段脚本**（太极、虚线框全消失）。兜底写法：
  `(typeof THREE.ShadowMaterial === 'function') ? new THREE.ShaderMaterial({color:0x2b2015, opacity:0.24}) : new THREE.MeshBasicMaterial({transparent:true,opacity:0})`
- 像素比上限 2（移动端 1.5）；页面切后台停掉渲染循环。

## 五、相机与取景

- 不写死距离。按 `camera.aspect` 推：`FIT_R=2.72`，方向 `DIR=(0.79,0.35,0.56).normalize()`，`d = FIT_R / sin(min(vHalf, hHalf))`；`resize()` 里 aspect 变化 >16% 重新 fit。
- 限位：`minDistance/maxDistance`、`minPolarAngle/maxPolarAngle`。允许转就必须限位，否则能转到看见空壳背面或穿进模型。
- `fov` 不用 75（库默认值）；35–50 给形体与尺度。

## 六、舞台与布局

- 舞台必须定高（`height:min(560px,72vw)`，移动端 400px），不能靠 `min-height` 撑——右侧长面板会把舞台拉成瘦高条，模型横向被切。
- 外层用 `align-items:start`。
- 模型表面**不写中文标签**：五字只出现在右侧图例（彩色圆点＋字）。这是用户明确否决过的方案。

## 七、交互

- 壁厚滑杆 `12%–100%`：拖动即重建几何（`Ri = Ro * (1 - t)`），不是缩放；同时刷新「壁 x% · 空 y%」与状态句。
- 四档预设：薄壁 15／中壁 35／厚壁 57／实心 100。移动端预设按钮 `repeat(2,1fr)`，避免最后一行只剩 1 个。
- 自动旋转默认关（匀速自转没有状态，仅作可选）；「复位视角」回到 `fitView()` 结果。
- `reduced-motion` 降级只停动画循环，**不跳过渲染**；首帧必须在 `load` 前画完，`window.__sceneReady = true` 供自检读。

## 八、验收

1. 桌面 1440×900 与移动 390×844 各一张截图，`consoleErrors` 为空。
2. 截图里主体可见、有明暗层次，五色能区分（不是一片灰粉）。
3. 杯：恰好 4 瓣＋1 底；管：恰好 5 瓣、无底、腔是通的。
4. 管拉到 100%：腔闭上，「空尽」文案出现，不出现几何自交。
5. 移动端正文 ≥14px，横竖都不横向溢出。
6. 文件里除 XML 命名空间外没有任何 http(s) 外链——离线可开。
